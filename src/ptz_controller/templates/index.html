Camera Presets

Custom setup

Save a complete setup: camera connection, controller, axes, deadzones, speed and button mappings. These presets are separate from the camera’s position memory slots.

Saving an existing name updates that preset. Selecting a preset loads its settings. If connected, it switches the connection automatically; otherwise, use Connect in the header.

Settings Controller, mappings, commands & testing

Controller & Motion

Analog axes

Select a controller to monitor its input. Move the sticks to identify axes. Deadzones rescale the remaining travel.

Button & D-Pad Mappings

Add a mapping, then press a controller button or D-pad direction. Controls are disarmed while listening. Click an input field or Listen to assign it again. Motion runs while held; other commands run once per press.

Camera Commands

Memory slots recall positions saved on the camera. Custom packets include the address byte and FF terminator; omit the network header.
