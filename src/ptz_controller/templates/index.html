Controller & Motion

Analog axes

Select a controller to monitor its input. Move the sticks to identify axes. Deadzones rescale the remaining travel. Precision response gives slow movement near center and full speed at full travel. Choose Gentle or Linear for a faster response.

Button & D-Pad Mappings

Add a mapping, then press a controller button or D-pad direction. Controls are disarmed while listening. Click an input field or Listen to assign it again. Motion runs while held; other commands run once per press. To switch cameras, choose Load and connect application profile, select a saved profile, then save this setup. Map the same button in the other profile to switch back. Release the button between switches.

Camera Commands

Memory slots recall positions saved on the camera. Custom packets include the address byte and FF terminator; omit the network header.
